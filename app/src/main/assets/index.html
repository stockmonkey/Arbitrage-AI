What this latency measurement means

We measure synthetic quote-comparison processing time in on-device JavaScript using a monotonic timer. This excludes external feeds, API round trips, network transit, broker routing and fills. Microsecond-scale local calculations do not imply microsecond-scale trading.

Local AI model (desktop only)

This Android prototype provides a clearly identified local rules-based research assistant. It does not run Ollama or download verified recent news. The desktop Mac version supports Ollama.

About TradingView and Wealthsimple

TradingView: charts open in your phone browser; the widgets cannot supply raw quotes to the detector. Wealthsimple: no supported public trading-feed connection is included, and the app does not scrape private endpoints or access your account.

Later: add authenticated, licensed venue feeds with executable bid/ask depth, synchronized timestamps and an independent execution risk gateway. No real order submission should be enabled until extensive paper validation and broker approvals.

Where your data lives

Virtual portfolios, simulation settings and events are stored in this Android app’s private local storage. The optional provider key is saved in private Android preferences. Uninstalling the app removes these records. The app has no broker connection and does not place orders.
